Descarga el archivo de ejemplo con los encabezados correctos, una fila de muestra y una hoja de instrucciones.

Encabezado Obligatorio Formato / valores válidos Ejemplo
nombre Sí Texto Certificación Seguridad Industrial
ciudad Sí Texto Bogotá
modalidad Sí Presencial / Virtual / Mixta Presencial
fecha_inicio Sí AAAA-MM-DD 2026-10-01
fecha_fin Sí AAAA-MM-DD 2026-10-02
cupo_maximo Sí Número entero 30
plantilla Sí Nombre exacto de una plantilla de certificación ya creada Certificado Estándar
descripcion No Texto Capacitación para operarios de planta
lugar No Texto Sala de Capacitación A
capacitadores No Correos separados por coma juan@empresa.com, ana@empresa.com
  • La primera fila del archivo debe tener exactamente estos encabezados, sin cambiar nombres ni orden.
  • Cada fila siguiente crea un evento nuevo; los eventos se crean en estado Borrador, sin participantes.
  • El valor de plantilla debe coincidir exactamente (mayúsculas/tildes no importan) con el nombre de una plantilla de certificación existente; si no existe, esa fila fallará.
  • Los correos en capacitadores que no correspondan a un usuario con rol Capacitador se ignoran silenciosamente (el evento igual se crea, sin ese capacitador).
